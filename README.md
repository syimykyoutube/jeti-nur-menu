# Жети Нур Меню

Кафелер үчүн QR меню долбоору. Талаптардын толук булагы — [TZ.md](TZ.md).

Азыр **0-кадам** гана аткарылган: долбоордун негизи жана бир жөнөкөй маршрут.
`GET /` сурамы `Жети Нур Меню` деген текст кайтарат.

## Керектүү программалар

- Node.js 24 LTS (npm кошо келет).
- git.

Версияларды текшерүү:

```sh
node --version
npm --version
git --version
```

Эгер жок болсо, Node.js LTS'ти <https://nodejs.org/en/download> дарегинен орнотуңуз.
macOS'то git жок болсо, `xcode-select --install` буйругун аткарып, ачылган терезеде
Command Line Tools'ту орнотуңуз. Орноткондон кийин терминалды кайра ачыңыз.

## Орнотуу

Терминалда ушул долбоордун папкасында аткарыңыз:

```sh
npm ci
```

Бул буйрук `package-lock.json` файлында бекитилген версияларды орнотот.
Hono — сурамдарды иштетүүчү жеңил китепкана. TypeScript коддогу типтерди текшерет.
Wrangler жана Cloudflare типтери иштеп чыгуу үчүн гана колдонулат.
Vitest ТЗдагы кийинки unit-тесттер үчүн орнотулган; азыр тесттер жазылган эмес.
Wrangler долбоордун ичинде орнотулат, глобалдык орнотуу талап кылынбайт.

## Компьютерде иштетүү

```sh
npx wrangler dev
```

Же ошол эле ишти аткарган кыска буйрук:

```sh
npm run dev
```

Терминалда көрсөтүлгөн даректи браузерден ачыңыз. Демейки дарек:
<http://localhost:8787>. Экранда `Жети Нур Меню` чыгышы керек.
Серверди токтотуу үчүн `Ctrl+C` басыңыз.

Башка терминалдан жоопту текшерсеңиз болот:

```sh
curl -i http://localhost:8787/
```

Күтүлгөн жыйынтык: `200 OK`, `text/plain` жана `Жети Нур Меню` тексти.

TypeScript текшерүүсү:

```sh
npm run typecheck
```

## D1 жана R2 жөндөөлөрү

ТЗда binding жана сактагычтардын так аттары берилген эмес. Бул долбоордо:

| Кызмат | Коддогу binding | Ресурстун аты |
| --- | --- | --- |
| D1 маалымат базасы | `DB` | `jeti-nur-menu` |
| R2 сүрөт сактагычы | `IMAGES` | `jeti-nur-menu-images` |

Алар `wrangler.toml` файлында жана `src/index.ts` типтеринде көрсөтүлгөн.
Миграциялардын келечектеги папкасы — `migrations/`.

`database_id = "00000000-0000-0000-0000-000000000000"` — локалдык текшерүү үчүн
убактылуу маани. Бул чыныгы Cloudflare базасынын ID'си эмес.
`wrangler dev` D1 жана R2'ни компьютерде иштетет; Cloudflare аккаунту жана булуттагы
ресурстар талап кылынбайт. Жергиликтүү абал `.wrangler/` ичинде сакталат.

## Сырлар жана git

Кийин жергиликтүү сырлар `.dev.vars` файлына жазылат. Аны git'ке кошпоңуз.
Булуттагы сырлар кийин `npx wrangler secret put PASSWORD_VIEW_KEY` сыяктуу
буйруктар аркылуу берилет. Азыр бул сыр талап кылынбайт.
`.dev.vars`, `.env`, `node_modules/` жана `.wrangler/` `.gitignore` ичинде бар.
`package-lock.json` версияларды бирдей кармоо үчүн git'ке кошулат.

## Кийин: Cloudflare'ге чыгаруу

Бул бөлүк — кийинки этап үчүн нускама. **0-кадамда деплой жасалбайт.**

Cloudflare аккаунту даяр болгондо:

```sh
npx wrangler login
npx wrangler d1 create jeti-nur-menu
```

Кайтарылган чыныгы `database_id` маанисин `wrangler.toml` файлына көчүрүңүз.
Эгер Wrangler конфигурацияга binding кошуп берсе, `DB` жазуусу бирөө гана
калганын текшериңиз. Андан кийин R2 сактагычын түзүп, Worker'ди чыгарыңыз:

```sh
npx wrangler r2 bucket create jeti-nur-menu-images
npx wrangler deploy
```

Бул кадамдар Cloudflare'де ресурстарды түзүп, учурдагы кодду интернетке чыгарат.
Толук меню, база таблицалары, админ панел жана башка ТЗ талаптары кийинки
этаптарда ишке ашырылат.
