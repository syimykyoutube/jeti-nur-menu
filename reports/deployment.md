## 16-октябрь: ачкыч жаңылоо жана тазалоо

- `openssl rand -base64 32` аркылуу жаңы 32 байт кокус ачкыч түзүлдү. Колдонмо
  талап кылган base64url түрүнө өткөрүлүп, `wrangler secret put PASSWORD_VIEW_KEY`
  менен өндүрүшкө коюлду. Сыр команданын аргументине, чатка же отчётко чыгарылган жок.
- `cloudflare-secrets.env` ичиндеги ачкыч ошол эле жаңы мааниге жаңыртылды;
  файлдын укугу `0600`. `.dev.vars` локалдык ачкычы өзгөргөн жок.
  `.dev.vars.production` — мурдагы файл; аны учурдагы өндүрүш ачкычынын булагы катары колдонбоңуз.
- PBKDF2 логин хэштери жана супер админдин паролу өзгөргөн жок. Эски ачкыч менен
  шифрленген тест owner паролу кайра сакталмайынча көрсөтүлбөйт; бул жандуу API'де
  **503** менен ырасталды. Супер панель/тамак формасы **200**, коомдук меню **200**,
  бир жолку setup **404**. Меню **91 684 байт**, gzip **6 452 байт** бойдон.
- Текшерүүчү скрипттердин эки сессиясынан `/admin/logout` аркылуу чыгылды (**303**).
  Колдонуучунун браузер сессиясына тийилген жок.
- Убактылуу чоң сүрөт баскычы коддо жана жандуу формада жок. Тесттин cookie/ID
  файлдары, жеке текшерүүчү скрипт, ачкычтын убактылуу көчүрмөлөрү жана тест PNG/patch
  тазаланды. Колдонмонун `test/` тесттери жана локалдык D1/R2 маалыматтары сакталды.
- `git check-ignore -v` үч файл үчүн тең `.gitignore` эрежесин тапты:

## Колдонуу жана кийинки деплой

1. `/admin/login` аркылуу өзүңүз тандаган супер админ логин/паролу менен кириңиз.
2. «Жаңы кафе» → KY аты, кошумча RU аты, уникалдуу slug жана кол менен тандалган owner логин/паролу.
3. «Кафеге кирүү» → категория/тамак/өлчөмдөр/баалар; сүрөт жүктөлгөндө «Сактоо».
4. `/{slug}` кардар менюсу. Админдеги «QR код» экранынан SVG/PNG жүктөлөт.
5. Кийинки код жаңылоодо `npm test`, `npm run typecheck`, `npx wrangler deploy`.
   Жаңы миграция болсо адегенде `npx wrangler d1 migrations apply jeti-nur-menu --remote`.
6. **Setup сырларын кайра кошуунун кереги жок.** Кийинки деплойдо толтурулган
   `cloudflare-secrets.env` файлын `--secrets-file` аркылуу кайра бербеңиз: анда
   мурдагы setup маанилери дагы болушу мүмкүн. Кадимки `wrangler deploy` учурдагы
   `PASSWORD_VIEW_KEY` secret'ин сактайт. Ачкычтын коопсуз резервдик көчүрмөсүн кармаңыз.

Сыноо кафеси жана сүрөттөрү жандуу сайтта калды; бул реалдуу кафенин жарыясы эмес.
Сыноо менюсунда айрым тамактар «Бүттү» абалында; owner панелинен
өзүңүз каалаган абалга которо аласыз. Убактылуу изоляция кафеси калган жок.
